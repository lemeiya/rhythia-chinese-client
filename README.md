# Rhythia 中文客户端版

**English name:** Rhythia Chinese Client Edition  
**Short name:** Rhythia-CC

Rhythia 中文客户端版是基于 [Sound Space Plus / Rhythia](https://github.com/David20122/sound-space-plus) 的独立第三方客户端版本，面向中文玩家提供本地化界面、客户端功能改进和社区服务接入能力。

本公开仓库只包含客户端及其运行所需的公开资源，不包含社区服务器或社区网站。

## 开源范围

本仓库不发布以下内容：

- 社区服务器源码和 PHP 服务端
- 社区网站、管理后台和 API 实现
- 社区数据库结构、生产数据和部署脚本
- Resend API Key、数据库密码、域名配置和其他生产密钥
- 用户上传的音乐、谱面、头像和社区内容

社区服务由项目维护者独立部署和运营，客户端只通过配置的 API 地址访问服务。服务端相关内容不属于本公开仓库的分发范围。

## 功能介绍

### 游戏与谱面

- 中文本地化界面，覆盖菜单、设置和游戏内提示
- 支持 SSPM v1/v2 谱面加载、导入和播放
- 支持暂停、重试、放弃、回放和队列连续游玩
- 提供速度、镜像、视觉效果、命中窗口等多项游戏设置
- 支持自定义世界、音效、光标、轨道和视觉效果

### 本地内容管理

- 管理本地歌曲、谱面、回放和自定义内容
- 支持谱面信息、作者、难度等内容展示与筛选
- 支持谱面格式转换和本地文件导入
- 保留用户的本地设置、成绩和缓存数据

### 在线社区

- 可连接配置的中文社区服务
- 浏览社区动态和在线谱面
- 下载社区谱面并导入客户端游玩
- 社区服务地址与客户端代码分离，便于独立部署和维护

### 平台与扩展

- 支持 Windows x86_64 客户端构建
- 支持控制器输入和 VR 相关功能
- 集成 Discord 状态显示和原生文件选择对话框

## 中文社区

访问 [Rhythia 中文社区](https://rhythia.fastmay.top/) 获取社区动态、谱面和其他中文社区内容。

## 开发环境

项目使用 Godot 4.3，请从 Godot 官网安装对应版本。

解析项目：

```powershell
godot --headless --path . --editor --quit
```

## 用户数据

游戏用户数据位于 Godot 的 `user://SoundSpacePlus` 目录，包含本地设置、回放、谱面缓存和其他个人数据。更新客户端时请勿删除该目录。

## 项目结构

```text
scripts/        Godot 游戏逻辑
scenes/         Godot 场景
assets/         游戏资源
prefabs/        可复用场景组件
localization/   本地化资源
```
